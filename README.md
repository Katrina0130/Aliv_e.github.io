# Aliv_e.github.io

这是一个纯静态的个人网站，适合在 GitHub Pages 上部署。你可以随时更新内容，而不需要改动太多页面结构。

## 快速更新方式

1. 打开 `content.js`
2. 修改 `window.siteContent` 里的文本、模块和社交链接
3. 保存后刷新浏览器即可预览
4. 提交并推送到 GitHub，GitHub Pages 会自动同步更新

## 关键文件

- `index.html`：主页结构
- `content.js`：主页内容配置，最适合日常修改
- `style.css`：页面样式
- `script.js`：语言切换与内容渲染

## 适合日常维护的内容

- 个人介绍
- 阅读/音乐/生活记录
- 关注入口链接
- 首页模块标题与描述

如果你想更新内容，只需要直接修改 `content.js` 即可，适合随时维护。
